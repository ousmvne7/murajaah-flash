# Workflow

Les recherches produit, les choix d'architecture, les licences, les APIs, les sources de données et les décisions UX sont validés en amont.

Ne refais jamais ces recherches.

Concentre-toi uniquement sur l'implémentation.

Si une recherche externe devient réellement nécessaire, arrête-toi immédiatement et signale-le.

---

# Règles

- Sois très concis.
- Priorité au code.
- Aucune explication sauf si demandée.
- Ne reformule jamais la demande.
- Modifie uniquement les fichiers nécessaires.
- Ne casse jamais une fonctionnalité existante.
- Respecte l'architecture existante.
- Réutilise le code existant avant d'en créer un nouveau.
- Évite tout refactoring inutile.
- Ne modifie pas plusieurs modules si un seul suffit.
- Les décisions produit sont considérées comme validées.
- Ne propose pas d'alternative non demandée.
- Ne devine jamais une API, une licence ou une source.
- Ne fais jamais de veille technologique.
- Ne fais jamais de comparaison d'API.
- Ne fais jamais de recherche produit.
- Ne pose une question que si une information manquante empêche réellement l'implémentation.
